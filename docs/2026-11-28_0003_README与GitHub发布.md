## 目标与背景

用户要求生成项目 README，并将项目推送到指定 GitHub 仓库的 main 分支。开始时目录没有 .git；旧 README 混合大量历史条件，需整理为当前 v5 的项目入口。

## 主要改动

重写 README，说明通用机制、模型与依赖、CLI、Web 归档前提、两种基模的最终成绩和 token、统计边界与来源。数据采用既有审计汇总，没有重新运行模型。原 README 备份保留在本地 artifacts。

扩充 .gitignore，保留源码、文档、第三方许可与精选结果摘要，排除权重、原始数据、运行缓存、用户会话、网页导出及未获再分发许可的上游快照。新增 .gitattributes 禁用隐式换行转换，保护冻结文件的逐字节哈希。项目没有整体 LICENSE，不擅自宣告 MIT 等许可。

初始化本地 Git 仓库，设置 main 分支及用户指定的 origin。

## 通用性与兼容

未修改 agent 核心、prompt、检索、停止机制、冻结配置或原始预测/评分。当前 Web 启动器依赖完整实验归档的限制如实注明。

## 验证与发布状态

README 的 17 个相对链接及其 Git 纳入范围、24 个成绩单元格、4 行 v5 token 数据、14 份历史来源 SHA256 均核对通过。待发布文件 762 个，合计约 7.8 MB；未纳入模型权重、原始数据、运行缓存或网页导出，常见凭据模式扫描没有命中。研究、BM25、Web 和 27B 评测入口的 --help 检查全部成功。纯文档与发布配置修改，未重跑模型、完整单测或浏览器测试。

HTTPS 连接没有可用 GitHub 凭据。为排除主机信任问题，从 GitHub 官方 HTTPS metadata API 获取主机公钥，写入被 Git 忽略的临时 known_hosts 后核查现有 SSH；服务器返回 Permission denied (publickey)。未修改用户的全局 SSH known_hosts，也未取得可用认证。

本地初始提交与实际推送结果将在完成后补记；不将本地提交当作远端发布。
