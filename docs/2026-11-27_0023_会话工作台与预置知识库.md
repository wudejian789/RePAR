## 会话与知识库

左栏改为持久化会话列表。新建会话时可绑定已有库，也可上传资料并立即进入建库中的会话。每次问答保存会话 ID 与库 ID。补问引用会检查归属，即使两个会话绑定同一知识库也各自读取历史。使用首问生成可选的会话标题。原有无会话 ID 的工作台运行从「历史对话」打开，沿用旧知识库链接以及真实轨迹。左栏之外可通过「浏览知识库」查看资料和原文，打开图谱或证据时再加载索引展示数据。[工作台说明](../webserver/README.md#研究工作台)

工作台接入 v5 冻结协议和索引清单中的一份 MATH 教材索引与 LongBench 的 125 份多文档索引。页面目录由逐题原文哈希与冻结索引清单匹配，查询时校验索引文件及其原文哈希。LongBench 各编号独立绑定原文范围。预置库的作答继续使用当前工作台模型配置和适配的嵌入编码器。8080 已添加一个 MATH 教材会话和一个 LongBench 文档会话。LongBench 示例绑定编号 33，按最短原文选取，用于快速浏览。两条历史评测链接仍指向 Case Lab。资料索引使用评测原文和教材，工作台继续执行通用 v5 问答流程。
