# 知识库管理与原文范围

时间为 2026-11-27 10:05，Asia/Shanghai。

## 交互与数据

工作台原有弹窗关闭按钮只注入了图标。为关闭按钮绑定原生 dialog 关闭操作。新会话直接在聊天工作区打开，用户可点示例填入问题，在输入框旁选库。发送首问时建立会话。新建知识库单独在管理页上传，查看构建状态、文件与索引规模，可查看完整索引或用该库开启对话。[工作台说明](../webserver/README.md#研究工作台)

输入框支持为本条消息指定最多 24 个原文块。服务端校验每个 ID 属于当前库，按原文顺序复用入选块的向量，在请求内构建原文范围内的树和实体关系图。通用 v5 仍使用正常的检索与反思流程。范围不会改写上传索引、冻结基准索引或历史轨迹。局部编号和原库编号的映射写入 Trace，前端按原库编号提供可点击引用。

图谱右栏初始显示全库原文块的搜索和分页。点击节点或连线会关联有出处的原文块，点原文块也可聚焦相关节点与边。原始画布未包含的原文块会带入其本地邻域。2D 聚焦使用平移过渡并尊重系统的减少动态效果设置。3D 保留交互和选中状态。
