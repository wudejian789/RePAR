# 数学补测：仅增加中间token预算

用户要求先检验反思预算问题，保持其他机制不变。本实验使用原数学补测冻结源码、教材索引、作答底座、judge和评分规则，只增加计划、动作选择及反思的生成token上限。**全部19题新条件及判分已完成，5007项审计断言通过。** 独立目录为`artifacts/math_2025_national_i_budget_v1/`，原v5实验不改写。[预算配对报告](../artifacts/math_2025_national_i_budget_v1/BUDGET_COMPARISON.md)和[机器对照](../artifacts/math_2025_national_i_budget_v1/budget_comparison.json)保留完整指标。

| 参数 | 原条件 | 新条件 |
|---|---:|---:|
| plan_max_tokens | 160 | 512 |
| action_max_tokens | 160 | 256 |
| reflection_max_tokens | 200 | 1024 |
| 最终回答上限 | 4096 | 4096 |
| 最大行动轮数 | 4 | 4 |

| 实际结果 | 原RePAR | 高中间预算RePAR |
|---|---:|---:|
| 反思首次长度截断 | 34/46轮 | 0/42轮 |
| 反思额外格式修复 | 36 | 0 |
| 作答/控制调用 | 193 | 145 |
| 作答/控制总输出tokens | 69470 | 66428 |
| 最终答案长度终止 | 10/19 | 10/19 |
| 最终答案长行重复≥3次 | 8/19 | 10/19 |
| 选择最终输出解析失败 | 9/11 | 10/11 |
| 实验折算分/150 | 14.5 | 15.0 |
| 整题完全正确 | 2/19 | 2/19 |

提高预算消除了本轮的反思输出token截断和格式修复，但未带来明确的最终准确率收益。总分净多0.5：Q17由1.25变5（+3.75），Q15由3.25变0（−3.25），其余17题得分相同。11份最终答案逐字相同；中间轨迹变化并不必然改变最终答案。长重复/长度终止未缓解，仍不能据此证明是底座“固有性”或归因于RePAR独有机制。

prompt、JSON字段maxLength、输入/证据预算、检索/图、答案解析、temperature、seed、thinking关闭及原修复策略均不变。原修复策略的第二次/第三次上限仍为`budget+80`/1024，未借此改动控制协议。字段长度限制与token预算是不同约束：本轮可检验输出token是否足够，不能保证消除schema字段达到上限或语义半句的问题。

## 对照范围与归因

- 全部19题RePAR用新条件重新执行，不按旧得分、失败或题型选样本。direct/BM25的预测及判分逐字节复用v5历史记录，不能称为重新实测。
- 保持0.8B标准Q4、9091和最终4096上限。9090的27B仍仅负责匿名数学评分；双评、分歧三评规则完全相同。
- 仅复用完全相同请求的judge缓存；作答/控制缓存只预置历史两条基线请求，未复制原RePAR预测、判分或控制缓存。同一请求若恰好共享最终prompt仍会如实记录命中。
- 复用与问题无关、结构配置完全相同的冻结索引，单列本次加载与历史建库，避免把缓存加载当作建库加速。
- 正式运行前冻结`budget_protocol.json`的谱系、预算差异、来源哈希和复用列表；suite本身另冻结`protocol.json`及算法源码。使用父实验快照创建隔离工作目录，排除仓库中的并行维护新增文件。
- 已知原试卷及轨迹，属于事后预算消融，不是未见数据的确认实验。固定一档更高预算，不根据分数继续挑预算。

重复输出也出现在direct及BM25。原结果仅支持“当前底座、长上下文与解码配置下三种方法共同出现重复/长度终止”，不能归因于RePAR独有缺陷，也尚未隔离证明是底座固有能力、量化、上下文长度、解码还是检索内容的影响。本轮只检验中间预算；即使重复增减，也不能由此单独证明底座或某个机制的因果作用。

## 预定观察指标

1. 46轮等原统计仅作父条件参考，新条件实际轮数由模型自主决定。统计每种中间阶段的首次长度终止、格式修复、实际tokens、schema字符上限命中及工具调用/终止原因。
2. 全19题实验折算分、整题全对数、逐题配对变化，同时展示未重新运行的两条历史基线。
3. 最终4096-token长度终止、选择题解析失败、同一长行重复；明确重复检测只是文本指标，不代替数学评分。
4. 新增调用与缓存复用分别列出。机器上其他已授权benchmark仍在独立服务运行，硬件共享会影响墙钟，不作隔离吞吐或加速结论。

## 执行与复核

```powershell
conda activate RePAR
python scripts/run_math_budget.py
python scripts/evaluate_math_snapshot.py --experiment artifacts/math_2025_national_i_budget_v1 --phase report --audit
python artifacts/maintenance/report_math_budget.py
```

`run_math_budget.py`先检查干预仅涉及声明的三项预算，再核验父快照，复用两基线，完成校准、RePAR生成、锁定答案哈希、数学评分及完整报告；可按ID继续，禁止覆写已完成行。`--prepare-only`只准备和校准。本次已实际通过准备、5项缓存复用校准及23项相关回归；额外检查拒绝偷偷更改最终预算、行动轮数、thinking或temperature。

产物包括`REPORT.md`、`summary.json`、`budget_protocol.json`、`generation_manifest.json`、`audit.json`、`budget_comparison.json`和`BUDGET_COMPARISON.md`，均已实际完成。19份新RePAR答案的145次作答/控制请求无缓存命中、无HTTP/工具错误；8份非选择题双评共16次评审，其中8次请求完全相同而复用旧judge响应、8次实际新评审，无分歧，未触发第三评。direct/BM25仍是历史复用，不计作新实验完成了57次生成。

冻结算法/数据/预算差异、原始请求与评分、来源offset、记忆重放、唯一ID与得分重算等5007项审计通过；23项相关测试通过，无skip。Q17首问的不同几何证明经抽查有效，judge最终unit评分接受了该路线；其原始细粒度check存在invalid标签与随后正确性解释不一致，记录保留，未趁本轮修改judge或人工改分。schema字符上限仍有27/42次assessment、21/42次gap、28/42次lesson触顶，属于本轮保持不变的另一限制。
