# RePAR v4：合法候选、独立查询与可续读原文

- 时间：2026-11-19 21:04，Asia/Shanghai
- 版本：react-v4；本文件描述本次实现及后续完整评测状态。

## 目标与比较边界

实现[跨底座分析](2026-11-19_2027_RePAR跨底座分析与通用改进.md)中的四项通用建议，用现有9091的Qwen3.5-0.8B-Q4_K_M完整测试19道MATH和125道LongBench Multi-Document QA。原教材、上下文、分块、树及实体图不清洗、不改写、不重建；评测只加载现有126份索引。

没有引入任务分类、固定树/图路线、专用算术工具或最终答案恢复/复核。仍是Plan → Action → 实际Observation → Reflection；模型选择继续或回答，执行器仅约束合法引用与资源。

## 四项实现

### 合法候选与请求身份

沿用v2的简短Plan和action_id选择形式。执行器依据当前query、已观察来源/实体/子树与显式配置绑定候选：焦点树搜索、分离通道融合搜索、子树搜索、实体查询、实体邻居、原文续读/邻近阅读、树浏览及有来源后的回答。展示顺序按轮次轮换；不规定某工具必选或最低取证轮数。

已完成的完整调用在模型选择前移出候选。请求身份是工具名与完整参数的确定性JSON序列化；不判断两个不同文本在语义上是否等价，没有数学、数字或否定词的专门解析规则。参数键顺序不影响身份，参数值变化就是不同请求。模型没有自由填入未经观察的节点ID。

### 独立查询通道

焦点搜索仅执行模型当前query。融合候选分别执行焦点与原始task两次查询，再用固定加权reciprocal-rank fusion合并：focus权重1、task权重0.25、rank常数20；这组通用配置在本次模型评测前固定，没有按题选择。两通道的真实参数和命中ID进入Observation。全文任务继续保留在控制状态中，不再自动拼到每一次搜索字符串上。

实体查询和邻居查询也执行当前焦点。树搜索零匹配不补无关来源；图邻居严格排除已检索来源。图边仍是未经验证的来源导航。

### 可续读原文及可见性

保留完整检索原文和不可变字符出处，另记控制器实际看见的范围。每个source view包含原始来源边界、显示边界、前后截断标志；read可用已观察来源ID、绝对offset和length继续读取，工具仍是原文read，未增加领域工具。

同一C ID的未见字符也算研究进展；完全相同范围不再增加进展。新增实体ID本身不计作新支持。树浏览首次发现的新scope计入可操作空间变化，随后重复浏览不增加。

Reflection收到的是实际source views，不是事先推测或固定900字符的无标记片段。暴露范围账本保存在state.exposures/visible_ranges，完整原文仍留在真实Observation中。来源不足和预算耗尽如实留痕。

### 跨来源覆盖与原文打包

已观察实体按当前query相关性、未见来源位置排序，再生成邻居候选，避免只用插入顺序前32个。模型可自主选择图，无图时保留其他接口。

最终证据在7000-token总预算内，按词汇相关性、冗余和已观察树分支覆盖选择连续原文范围，尽量保留邻近句子/段落边界。先分配来源份额，再用剩余预算补充更多原文范围；同一来源可有多个不重叠窗口，取消统一850-token上限。没有文本清洗、事实改写或把模型反思作为最终事实。

该策略是可解释的词汇启发式，不宣称已实现语义蕴含验证、文档级精确分类或完备证据。英语spaCy后端的中文覆盖限制继续存在。

## 配置与入口

- 可选依赖：`python -m pip install -e ".[dev,graph,agent-v4]"`；英语解析后端安装方式沿用现有项目说明。
- 核心：src/repar/v4；评测适配：repar.benchmarks.v4_suite.V4Suite，只覆盖research_result。
- 普通知识任务：`python scripts/research_kb_v4.py --context knowledge.txt --task "研究任务"`。
- 全量评测：`python scripts/run_repar_v4.py --config configs/v4_experiment.json --phase all`。
- solver仍为9091、标准Q4、temperature0.1、seed42、thinking关闭，窗口262144。没有调整generation参数。
- 控制：Plan256、Action128、Reflection768，最多4轮；原文观察和控制预览各3200 tokens；最终原文7000 tokens。预算与旧版不完全相等，不作等计算成本的因果声明。
- MATH最终仍4096-token原始回答；LongBench仍128-token及原grammar。数学非选择题继续由9090的27B匿名双评，单位credit有分歧则三评，使用原rubric和聚合。
- 输出：artifacts/repar_v4_20261119；全新请求缓存，不导入历史预测或缓存。旧方法仅作明确标注的历史对照。
