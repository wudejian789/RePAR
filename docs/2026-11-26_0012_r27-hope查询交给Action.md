# r27-hope 将查询交给 Action

时间为 2026-11-26 00:12，Asia/Shanghai。

基于最早的 r27 做一次 0.8B 配对实验，检验把查询词交给 Action 后是否改善查证和作答。两套数据复用历史原文、分块、树、实体图和词法索引。MATH 使用最早 r27 的历史索引、4,096-token 自由文本和原折算分规则。LongBench v2 Multi-Document 使用原 RAG 提示、128-token 预算和四选一 GBNF。模型、服务默认采样、种子 42 和作答请求参数以最早 r27 为对照。[候选配置](../configs/v4_experiment_r27_hope.json) · [历史对照](2026-11-20_2027_RePARv4-r27通用查询与反馈评测.md)

Plan 每轮只生成一个 `objective`。Action 从 r27 原有的绑定候选中选择工具，搜索和图查询同时输出 `query`。候选的工具、范围和预算由执行器绑定。原任务通道仍由 Action 选择。执行器在绑定查询后拦截已完成的同一调用，并把阻拦原因传给下一轮。Reflection 读取真实 Observation，沿用原字段与停止条件。Action 的请求含 Plan 已收到的证据预览和近期行动，供它拟定查询。[控制流程](../src/repar/v4/workflow.py) · [Action 契约](../src/repar/v4/selection.py)

独立馆藏查证用例核对了只有目标的 Plan、Action 同语种改写、重复调用拦截和已有来源的读取。95 项定向检查以及 237 项全量测试通过。全量测试有两条上游依赖警告。这是已见数据上的开发对照。

两套评测分别完成 19/19 和 125/125。37,745 项审计通过，包括逐题历史索引、最终请求配置、原文偏移、Action 生成参数和数学原判分规则。MATH 从 40.417 降到 36.167/150。LongBench 从 33 降到 32/125，其中 6 题只有 r27 答对，5 题只有 r27-hope 答对。[逐题分差及用量](../artifacts/repar_v4_r27_hope_20261126/comparison.json) · [运行审计](../artifacts/repar_v4_r27_hope_20261126/audit.json)
