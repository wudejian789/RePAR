## 统计口径与限制

所有在线结果仅取 seed 42，0.8B 为 Qwen3.5-0.8B-Q4_K_M，27B 为既有 Qwen3.8-27B-UD-Q4_K_M。未测组合全部为“-”；27B v5 没有实测，不移植 0.8B 结果或历史 v4 结果。

MATH 精度单元格为实验折算分 /150 及整题全对数 /19；LongBench 为 v2 Multi-Document QA 的准确率与正确题数 /125，不代表整个 LongBench。

表中 token 均为生成式 LLM 的逻辑 usage。总 token = 一次历史建库输入与输出 + 本轮在线输入与输出，不含阅卷和 embedding。在线包含 v5 草稿、Plan、Action、Reflection 及最终作答；基线为已归档证据上的在线作答。

建库成本不是本次重建：基线沿用各自历史摘要/抽取索引及已审计建库消耗；v5 复用 r60 的 768-token 索引。v5 用 EmbeddingGemma 建树与 spaCy 抽图，不调用生成式 LLM，所以建库 LLM token 为 0，不代表无建库成本。其原文正文按 EmbeddingGemma tokenizer 统计为 MATH 633,724、LongBench 17,478,760 tokens；这是正文规模，非含前缀的完整 embedding 执行计量，不与 LLM token 相加。原索引逐库 build_seconds 合计为 MATH 200.09 秒、LongBench 5,378.97 秒，后者是逐库用时之和，不是并行墙钟。

LongBench 的 RAPTOR、HippoRAG2、HyperGraphRAG 分别有 4、116、4 题缺少历史可复用证据，按错误保留在 125 题分母中，其新在线请求分别为 121、9、121 次。失败建库已有完整响应的 token 纳入历史建库；无完整响应的未知生成量不估算。

RAPTOR 的历史建库各含一次客户端缓存命中；输入 token 含服务端前缀缓存对应的逻辑输入量。这里没有以缓存命中或总 token 推断真实 GPU 用时。

各冻结条件的生成、索引和评分协议保留原设置。baseline 的 MATH 来自既有全题型 27B 阅卷版本；v5 沿用其原卷面评分规则（单选/多选解析，其余 27B 阅卷），不是重新统一评分的严格配对实验。JSON/CSV 单列了已记录的阅卷 token 与调用，不计入展示总量。

最终 v5 由用户明确选择为 Direct answer 8,192 tokens、seed 42；MATH / LongBench 最终作答仍为 4,096 / 128 tokens。只冻结这一已完成条件，没有运行 43/44、27B v5 或补测缺失 baseline。两个 benchmark 此前已参与开发，单种子结果不视作未见测试确认。
