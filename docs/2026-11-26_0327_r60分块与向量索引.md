# r60 的 token 分块与语义检索

时间为 2026-11-26 03:27，Asia/Shanghai。

r60 以最早 r27 的 Plan、Action、Reflection 和作答接口为起点。EmbeddingGemma-300M 的 tokenizer 按原文字符偏移确定块边界。优先使用接近上限的段落或句末位置，并对切出的原文字串重新计数。每个块保留精确的起止偏移，原文区间首尾相接。

每个叶子使用模型的 document 提示编码，查询使用 query 提示编码。两者均归一化为 768 维向量，内积即余弦相似度。相邻块相似度参与树的有序切分。内部节点用覆盖叶子的平均向量再归一化。树检索的 hybrid 模式允许范围内向量得分最高的两片叶子补充树路由候选。r27 原有双路候选可分别查询焦点和原任务，再按排名融合。[实现](../src/repar/dense_index.py) · [模型来源](https://www.modelscope.cn/models/google/embeddinggemma-300m)

图抽取沿用 spaCy NER 与依存分析。块中有汉字且汉字数不少于连续拉丁字母组数时使用 `zh_core_web_sm`，其余块使用 `en_core_web_sm`。中文用命名实体和依存名词组补足该模型的 noun_chunks 接口。图沿用实体、带出处的陈述、谓词关系与共现边。中英混合块使用一个模型，支持范围取决于这一语言判断与 spaCy 模型。[图抽取](../src/repar/entity_graph.py)

评测比较 192、384、768、1024 四档最大正文 tokens。EmbeddingGemma 的文档提示和特殊词元计入模型的 2,048-token 输入窗口核验。各档建立一套索引后供种子复用。首轮按种子 42、43、44 探索三种初始块大小。用户随后要求该版本后续采用单种子，1024-token 及 r61 配对只使用种子 42。MATH 全国 I 使用 4,096-token 自由文本，LongBench v2 Multi-Document 使用 128-token 选项 GBNF。历史 r27 三轮均值为 MATH 34.319/150、LongBench 30.667/125。数据已参与前期开发。[历史均值](../all_results_new.md#r27-hope3-与最早-r27-三种子复测)

## 运行入口

`python -m pip install -e ".[dense-index,graph,agent-v4]"` 安装依赖。环境需要支持 CUDA 的 PyTorch 或通过日常任务配置指定 CPU。安装 `en_core_web_sm` 和 `zh_core_web_sm`。权重存入 `models/EmbeddingGemma-300M/`，文件来源、版本与 SHA-256 记录在 model manifest 中。

`python scripts/run_r60.py --sizes 192 384 768 --seeds 42 43 44` 建库并评测。该入口在 `--phase index` 下构建索引，在 `--phase evaluate` 下继续评测。各档索引和每种子记录存入 `artifacts/repar_v4_r60_20261126/`。用 `python scripts/report_r60.py` 核对覆盖、请求参数和来源并生成对照数据。[运行入口](../scripts/run_r60.py) · [审计入口](../scripts/report_r60.py)

## 验证

真实 EmbeddingGemma 模型的中英混合用例覆盖短块限制、语义搜索及中英文谓词抽取。相关 102 项测试和全量 241 项测试通过。正式建库使用 CUDA 批量编码和多个 CPU 工作进程完成 spaCy 提取，两步通过原文区间连接。[模型文件清单](../models/EmbeddingGemma-300M/source_manifest.json)

首次评测启动时，并发加载 EmbeddingGemma 触发 PyTorch 的 meta tensor 错误。主线程改为先加载模型，再启动预测线程。失败运行在产生成功预测前归档。[启动错误与续跑记录](../artifacts/repar_v4_r60_20261126/tokens_192/evaluation.log)

四槽位 0.8B 服务的加速试验用 36 条实际请求重放，只有 10 条返回了完全相同的文本。正式比较统一运行于历史单槽位服务。四槽位试验的输出单独保存。[重放记录](../artifacts/repar_v4_r60_20261126/batch_trial.json)
