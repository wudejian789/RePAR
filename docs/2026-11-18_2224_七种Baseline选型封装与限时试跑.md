# 七种Baseline选型、封装与限时试跑

- 时间：2026-11-18 22:24，Asia/Shanghai（UTC+08:00）。
- 范围：本次会话合并记录；仅小规模效率筛选，完整125题实验待用户review。

## 目标与背景

用户要求判断RAPTOR、HippoRAG2、RAGen、DO-RAG、CoT-RAG、HyperGraphRAG、T3能否作为RePAR baseline，优先封装适合且有作者代码的方法，准备其余论文，再用当前Qwen在LongBench v2做限时试跑。配置和在线服务实际为Qwen3.5-0.8B标准Q4、关闭MTP，用户文字“0.58”没有被当作新模型或用来静默切换部署。

开始时阅读AGENTS、根README、docs索引与相关维护日志，核对真实目录、依赖和服务；工作目录无git元数据，本次未声称提交git commit。未派生子agent。

## 主要改动与决策

- 七种方法各自保存paper.pdf、README和sources.json，catalog登记选型。七篇PDF标题与SHA核实；五个可核实作者仓库固定commit存入third_party/baselines，共239份源码/配置/许可文件，不修改作者快照。
- RAPTOR、HippoRAG2、HyperGraphRAG提供普通文本任务Retriever、retrieve/answer、独立CLI和薄LongBench adapter。调用真实作者核心算法，不把自写相似方法冒充复现。建库接口只接收原文与配置，不接收问题或标签。
- 公共BoundedLLMClient为中间调用移除答案grammar、串行调用、限制deadline与单次HTTP超时并留存真实请求响应；最终作答单独恢复已有答案约束。SentenceEncoder置于repar公共模块，冻结MiniLM并在CPU上分窗编码。
- 用配置中的Qwen替换远程商业LLM，三者统一MiniLM；保留上游聚类、OpenIE/PPR、超关系/gleaning。Hippo/Hyper使用本地存储并绑定原文、配置、encoder和源码身份，拒绝混用索引；RAPTOR在内存重建。
- RAGen属于数据生成/训练适配条件；DO-RAG未核实作者仓库；CoT-RAG主方案涉及专家树/案例，另有Zero-expert消融，公开入口仍有未定义类及占位内容；T3需额外教师thinking traces。分别保留来源与未实现原因，不提供猜测式或伪成功接口。CoT/T3快照未见LICENSE，暂不再分发或执行。
- 补optional dependencies、来源/encoder准备、限时pilot、请求审计和wheel验证入口，同步README/专题报告。来源默认锁定commit，显式refresh才更新，已有来源hash异常不静默覆盖。CoT的GitHub元数据API限流后用同commit官方归档恢复下载并留痕。

## 通用性检查

修复位于模型桥接、上游导入兼容、源身份和评测边界，不向核心prompt加题ID、答案或领域关键词。独立机制fixture使用虚构人物/天文台，实际运行树/图算法，模拟输出不混入真实实验。未做权重训练、跨任务经验记忆或固定研究路线；pilot全文建库，问题/选项仅在查询时传入，gold在最终作答后评分。

同最终LLM不等于同总资源：新候选增加encoder、固定示范、离线摘要/抽取，top_k语义及证据token预算也不同。本轮采用作者检索组件，没有复现论文默认强LLM/encoder或宣称论文成绩；完整比较应单列成本并考虑同encoder dense control。

## 验证与结果

- 普通与严格隔离Python均运行tests和webserver/tests：33项通过，无skip，2项上游警告。最终输出在artifacts/maintenance/baseline_pytest_20261118.txt。
- 独立fixture验证实际UMAP/GMM摘要树、Hippo OpenIE/PPR、Hyper超边hybrid及原文出处。最初发现绝对动态import、Chunk对象类型和event-loop helper位置等桥接问题，已在适配层修复，未改作者快照。
- wheel构建成功，仓库外pip --target安装后用python -I导入三个方法、加载固定来源与共同prompt成功；真实MiniLM将超窗fixture分3窗输出384维。wheel约76KB，不含第三方源码、PDF或权重，资源根由REPAR_REPOSITORY显式提供。
- 隔离检查暴露filelock/jinja2/mpmath/networkx曾依赖用户site；同版本固定到RePAR环境，补MarkupSafe后隔离pip check与33项回归均通过。baseline依赖安装时wrapt/python-dateutil亦按约束调整，当前版本详见环境JSON。
- Pilot先冻结各档最短完整原文、180秒/题、60秒/HTTP门槛。BM25三题5.8/5.9/5.9秒；RAPTOR三题31.6/60.2/134.4秒，通过三档门槛；摘要节点7/46/141个且实际检索选中摘要。
- Hippo最短题179.5秒、Hyper最短题179.2秒，均建库失败，未完成检索/作答；大量输出达到长度上限。按预定门槛各跳过更长两题。8项实际执行、6完成、2失败、4项门槛未运行，不把失败或跳过记为完成。
- 288个真实完成响应核对请求身份、部署、解码、无缓存命中、中间调用无答案grammar、6次最终答案grammar；39份执行源码与冻结hash一致。7篇PDF和239份源码/配置/许可文件hash校验通过。之后新增的每方法adapter只是薄委托到冻结公共adapter。
- 透明披露BM25三题2/3、RAPTOR三题1/3正确；长度最短样本不能估算准确率、挑参或作为优劣结论。全部预测和失败日志保留，未用测试答案优化代码或prompt。
