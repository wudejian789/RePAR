## r33 作答证据筛选

r32 在 LongBench 扩大了证据覆盖，但结构化引文输出常遇到复制错误和预算截断。MATH 的既有单段移除重放也显示，同一题面和生成设置下，一个词汇相关但偏离题意的片段足以改变作答行为。[r32 评测](2026-11-25_0040_v4引文核验与检索控制.md) · [单段移除重放](../artifacts/benchmark_r31_08_20261124_diagnosis/math_q4_without_c440.json)

r33 从轻量的分阶段 r27 控制出发，沿用 r29 的同语种焦点查询与原任务查询。最终作答前，用原任务和实际执行过的焦点查询对已返回的片段重排，片段的匹配权重来自已返回来源中的词项频率。按各查询下的秩融合原文窗口，去除重复或重叠窗口，按独立的最终证据 token 预算打包。词项来自运行时的检索分词器，原文内容及出处以索引偏移为准。查证过程仍可浏览、读原文和使用图查询。[证据筛选](../src/repar/v4/answer_evidence.py) · [配置](../configs/repar_v4_r33.json) · [评测入口](../scripts/run_v4_candidate.py)

独立测试覆盖跨查询的互补证据、重复原文剔除、无词法支持段落的排除及原文偏移。结果与线上用量读取对应版本的预测、调用和阅卷记录。[机制回归](../tests/test_v4_answer_evidence.py)

种子 42 完成 19/19 道 MATH 和 125/125 道 LongBench，取得 **23.750/150** 和 **27/125**。MATH 有 10/19 份作答触及 4K。两项均低于历史目标，保留这一轮的全部结果并继续下一版。[首轮审计](../artifacts/benchmark_r33_08_20261125/summary_seed_42.json)

## r34 研究笔记与作答输入

r33 的证据筛选有时把相关片段和用来推导的背景割裂。控制轨迹中有些可见原文的初步判断也没有交给最终模型。r34 恢复 r29 的完整原文打包。一次已有的 Reflection 产生的初步判断，仅在其引用的来源均出现在当时反思及最终作答视野时，作为待核实笔记随原文传递。MATH 适配层将公开题面、选项、小问与表格从 JSON 渲染为连续题面，按题型提示输出格式，仍统一用自由文本解码。LongBench 沿用原评测提示和四选一 GBNF，笔记放在检索背景区并与原文分开标记。[研究笔记](../src/repar/v4/working_notes.py) · [评测适配](../src/repar/benchmarks/v4_suite.py) · [r34 配置](../configs/repar_v4_r34.json)

种子 42 取得 **26.250/150** 和 **29/125**，MATH 8/19 份作答触及 4K。同轮同时改变了证据打包、笔记和题面呈现，分差无法归因到单项变化。[首轮审计](../artifacts/benchmark_r34_08_20261125/summary_seed_42.json)

## r35 原文范围引用

## r39 作答输入顺序

## r41 有界反思推理

## r51 保留片段的搜索词

对 r49 的数学轨迹核对每个结果的来源绑定，发现最终作答中有 15 个按题统计的片段曾有对应搜索词，但后来一次读取或单通道查询覆盖了绑定。r51 让单通道搜索也记录匹配词，随后同一片段由原文读取或图查询再次返回时保留已有的匹配词，有新的搜索结果时采用新的绑定。显式的原文游标读取直接按指定区间返回。独立回归通过真实查询 API 检查这两个操作的衔接。[r51 配置](../configs/repar_v4_r51.json) · [回归用例](../tests/test_v4.py)

评测审计原先从逐题 JSON 核验数学分数，但沿用旧汇总文件的完成标记和阅卷用量，导致已核验的候选报告里可能显示 `complete=false` 与 `grade_count=0`。从 r51 起，报告统一从逐题 JSON 汇总完整性、阅卷时间和 token。历史报告保留原样。

r51 完成双评测，MATH 40.417/150，LongBench 33/125。对照 r50，MATH 的全部作答与总 token 一致，LongBench 少答对一题。含本轮分词与绑定回归的全量测试为 231 项通过、2 条上游依赖警告。[r51 审计](../artifacts/benchmark_r51_08_20261125/summary_seed_42_math_longbench.json)
