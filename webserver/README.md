## 启动

在仓库根目录运行以下命令。

```powershell
conda activate RePAR
python -m webserver.server --port 8080
```

打开知识问答后，顶部导航可切到知识库管理与评测。**启动不需要历史实验归档、模型权重或预先生成的页面数据，不运行评测导出和模型推理。**默认从 `artifacts/studio_v5/` 读取已保存的知识库、会话与问答，从 `webserver/data/` 读取评测页面缓存；存在就加载，不存在就显示空列表/暂无结果。缺少某个数据集的缓存不影响其他页面。案例展示使用 Python 标准库和本地静态资源。[知识问答](http://127.0.0.1:8080/studio) · [LongBench v2](http://127.0.0.1:8080/) · [MATH 2025](http://127.0.0.1:8080/?dataset=math)

在全新源码克隆中，可以先 `python -m pip install -e .` 后启动空工作台。实际上传建库时才加载 EmbeddingGemma 和 spaCy，提交问答时才连接配置的模型。模型与运行参数见 [项目配置说明](../README.md#配置文件与运行参数)。可显式选择配置和保存位置：

```powershell
python -m webserver.server --port 8080 --studio-config configs/repar_v5.json --studio-root artifacts/my_workspace
```

工作台记录会持久化，重启后自动读取。CLI 的 `artifacts/indexes_v5/` 是研究命令的缓存，不是 Web 知识库注册表；在网页使用的新资料请通过知识库管理上传。兼容的本地冻结示例库也会自动发现，缺失或不完整时跳过，不阻止服务启动。

若需要主动从完整的历史预测、索引与请求归档生成评测页面，可独立运行 `python -m webserver.build_data`。这是可选的离线导出操作，需要其对应的源归档；Web 服务本身从不自动执行。旧的服务参数 `--rebuild` 已移除，避免将服务启动与历史导出耦合。

## 研究工作台

左栏列出保存的会话。点「新建会话」进入欢迎页，可用示例填入问题。发送首问时建立会话。输入框旁为本次提问选择参考库，重新打开会话时优先显示最近一轮所用的库。点击回答下方的出处编号即可就地查看该轮所用库里的原文块，再点一次收起。历史原文范围问答仍按当时记录的编号映射读取出处。[研究工作台](http://127.0.0.1:8080/studio)

点会话旁的删除图标可永久删除该会话及其问答和执行轨迹。知识库仍可在其他会话中使用。排队或运行中的会话可在完成后删除。

「知识库管理」默认显示所选库的详情，包括建库状态、来源文件、原文块和实体关系数量。库就绪后可用顶部标签在「知识库详情」「浏览完整索引」与「知识图谱」之间切换。点「用此库提问」进入知识问答，输入框预选当前库。上传一份或多份 UTF-8 文本后，后台分块、生成嵌入、建立有序树并抽取实体关系。上传请求上限为 16 MiB，PDF 和 Office 文档需先转成 UTF-8 文本。[知识库管理](http://127.0.0.1:8080/studio/libraries)

当本地冻结资料可用时，输入框和管理页提供 MATH 2025 的数学教材库与 LongBench v2 的 125 个多文档原文库。LongBench 每个编号对应一个文档集。示例库加载 v5 评测使用的冻结索引，试题答案、评分和历史模型响应在评测页查看。

在「知识图谱」中，右侧可搜索或翻页浏览全部原文块。点击原文块后，2D 画布与 3D 镜头都会平移并放大关联的节点和连线。点「查看原文」会在右栏下方展开全文，实体和关系的出处也在此处阅读。大库的画布先显示部分索引，点击未上图的原文块可加载其邻域。3D 需要浏览器支持 WebGL 2，工作台从本地加载 Cytoscape 3.33.1 和 Three.js r180。[Three.js 许可证](static/vendor/THREE-LICENSE.txt)

勾选「接续上一问」会用同一会话最近一次已完成的问答解释指代。跨库时只传入上一问。提交后，当前回复显示已用时间与实际进度。执行轨迹在桌面右侧实时更新，手机端显示在输入区下方，可收起。选择较早的步骤会保留当前阅读位置，可点「跟随最新」恢复自动跟随。

选择一个模型步骤，展开「模型原始输入与输出」即可查看实际输入的消息正文，可切到「输出正文」或「JSON」。输入保留角色、顺序和换行。遇到格式修复等多次调用时，可按次数切换。Observation 按工具展示实际参数、完整返回和提交给 Reflection 的观察。完整模型请求可在对应的 Reflection 步骤查看。

在 Observation 的工具下展开「原文出处」，可以在各片段编号下直接展开当时记录的正文。同一原文块的多个片段按字符区间分别显示，可同时展开。

轨迹顶部按已记录的模型调用汇总输入和输出 token，运行中随调用完成更新。展开模型步骤可查看单次调用的输入、输出和用时。缓存复用会单独标记，累计用量使用该调用保存的原始计数。缺少用量的历史调用会标记为未记录，部分缺失的汇总会注明覆盖次数。

「完整 Trace」包含用量、工具结果、终止原因和「事件 JSON · 原始调试记录」。事件 JSON 是时间线读取的结构化事件，含轮次和执行进度。完整 Trace 支持下载 JSON 和通过运行链接重新打开。旧工作台问答按知识库显示为「历史对话」，延用原有运行链接。

聊天消息用本地 KaTeX 0.16.47 输出 MathML，支持 `$…$`、`$$…$$`、`\(…\)` 和 `\[…\]`。长回复默认显示预览，可展开或收起。调用记录保留 LaTeX 与其他原始文本。[KaTeX 许可证](static/vendor/katex/LICENSE)

工作台使用 [v5 配置](../configs/repar_v5.json)。建库需要 EmbeddingGemma、PyTorch 和中英文 spaCy 模型，问答需要配置的模型服务。依赖安装见 [项目 README](../README.md#环境安装)。用 `--studio-config` 指定其他 v5 配置，`--studio-root` 指定持久化目录。默认数据位于 `artifacts/studio_v5/`，包含原文、索引、问答和调用记录。服务默认监听回环地址，适合本地单用户使用。建库和问答共用一个后台任务队列。

## 逐题复核

默认对比 0.8B 历史直接回答和 v5 种子 42。可切换历史条件并从「查看当前题目」直接进入问答详情。v5 的执行轨迹提供当时保存的先验草稿，评分来自冻结记录。不同历史条件的配置可查对应实验记录。[v5 实验与配对对照](../docs/2026-11-26_1707_RePARv5先验草稿与研究工作台.md#全量结果)

- 在页面上方切换数据集、X/Y 方法和指标。正方形散点图的两轴共用范围和刻度，虚线表示 X = Y。可点击散点或独立滚动的题目索引打开记录，按关键词、题型或领域和双方评分筛选。链接保留数据集、题目、比较组合和指标。
- 逐题详情按 X/Y 顺序显示当前方法的原始回答、评分、证据数、用量、缓存情况和 RePAR 调用轨迹。MATH 展示题目分值、参考解答、表格与图示记录，以及开放题逐次 LLM 评审的小问评分理由。模型评审接受等价答案和正确的其他解法。
- 展开「最终模型输入」可查看最终作答 API 请求的全部消息内容，按原角色和顺序显示，包含当时实际传入的知识文本和题目。长输入在展开时加载。已有网页数据可用 `python -m webserver.build_data --final-inputs-only` 单独补导出。
- 「实际检索证据」与「知识库检查」随当前比较切换。有两个可用条件时可以切换来源，有一个时直接显示。证据阅读器展示运行中的最终原文切片，以及可选的已召回片段。v1/v2 历史证据阅读器附带 v2 离线实体索引的分析信息。每次真正执行的工具和交给控制器的观察可在原始轨迹中检查。
- 「知识库检查」按方法浏览完整索引。树上可沿父子层级下钻，原文节点和实体图联动。点击实体可查看邻接关系和跨片段提及，点击边可查看方向、关系类型、限定词、陈述及原文出处。图画出当前范围内少量关系，可逐页查看该范围全部关系，也可按关系、实体、节点 ID 或原文全库搜索。边为自动抽取的检索线索，共现以虚线显示。BM25 同一面板提供有序原文分块、区间与全文搜索。
- 可导出当前比较 CSV、题目 JSON 和实际 RePAR Trace JSON。LongBench 采用标准答案精确匹配。MATH 的散点和总分使用实验分，包含部分分。

## 数据与验证

导出器核对新条件的冻结文件哈希、逐题唯一覆盖、原文哈希和证据切片。RePAR r27 树与实体图来自冻结索引。BM25 按冻结分块参数和原文复现边界，检索结果仍来自历史预测记录。单次导出不调用模型、重新评分或清洗资料。

模型计算时间为作答侧全部 LLM 调用的预填充与解码，包含缓存请求的原始计算成本。在线实测时间包含索引加载、检索、LLM 及本地处理。

```powershell
python -m pytest webserver/tests -q
```

浏览器测试需要 Playwright 和本机 Chrome / Edge。可用 `REPAR_BROWSER` 指定浏览器，或运行 `python -m playwright install chromium`。
