# 2025年全国新课标Ⅰ卷数学：核对后的题目与参考解答

最终文件为 [MATH_2025_NATIONAL_I_QA.jsonl](MATH_2025_NATIONAL_I_QA.jsonl)：UTF-8、每行一个题目对象，按Q1～Q19排列，共19题、150分。原始PDF、`math_questions_solver.json`及`math_questions_evaluation.json`保持不变。

## 核对依据与实质修正

- 题目、选项、答案及参考解法以本目录《数学●全国Ⅰ卷丨2025年普通高等学校招生全国统一考试试卷及答案.pdf》为准。该PDF共36个物理页：第1～5页为试题，第6～36页为带答案解析的版本。记录中的页码均为从1开始的PDF物理页码。
- 原PDF未标各道解答题的满分，只标5题合计77分。第15～19题的13、15、15、17、17分，另据[锦宏教育真题转载](https://jhgk.cn/upload/file/20250608/1749350568467081853.pdf)题号旁的分值括注核对，并写入各记录的`score_source`。该转载仅作为单题分值补证，不替代原PDF的题干、选项或答案。
- 参考证明与演算按照原PDF进行人工核对、符号规范和步骤重排；各小问保留完整可检验的解答，而非逐字复刻PDF排版。没有为小问或步骤编造官方评分点。

## 证明与解题步骤

第15～19题的13个小问全部补全：

- 第15题：条件概率估计、零假设、χ²代入计算、临界值比较和检验结论。
- 第16题：等差数列证明、通项公式、导函数与错位相减全过程。
- 第17题：面面垂直证明、球心位置证明及两种求角方法；补录坐标法和几何法。
- 第18题：椭圆参数、R坐标的向量法与斜率法、P的轨迹圆及最大距离，并核验取等点满足P不在y轴上的限制。
- 第19题：区间最大值的导数法与均值不等式法、余弦不等式存在性证明、b的必要下界及全实数范围内的充分性；补录参考解析的两种下界论证。

第1～14题也提供了解题步骤。

## 原PDF本身的笔误与处理

- 第15题附表将`k=3.841`对应的χ²(1)上尾概率印为`0.005`；实际应为`0.050`。规范题干及临界值表使用修正值，同时在`source_original_rows`和`source_notes`保留原表。该笔误不影响本题使用的`α=0.001`及`k=10.828`。
- 第19题参考解析中存在φ=π时的错误恒等式、求导遗漏因子2、将第（2）问闭区间改成开区间等中间书写问题。最终JSONL采用有效参考路线并规范这些环节；`φ=0`时的上界覆盖全部实数，未只依赖第（1）问的有限区间结论。
- 第11题的角度讨论明确补足了由`cos A cos B sin C>0`推出A、B均为锐角的前提。第15题检验结论中的概率表述规范为第一类错误概率控制。

## 字段说明

| 字段 | 含义 |
|---|---|
| `id`、`section_instruction`、`question_stem`、`choices`、`category` | 继承原solver的接口，修复内容错误；选择题选项按A～D排列 |
| `answer_key`、`answer_values`、`score` | 继承原evaluation接口；修正错误答案与单题满分，证明结论详见子问题 |
| `question_number`、`question_type` | 题号及单选、多选、填空、解答题的明确区分 |
| `subquestions` | 每个解答题小问的题号、要求及结论 |
| `solution_steps` | 按小问和方法组织的步骤数组，含`subquestion`、`method`、`steps`、`conclusion` |
| `reference_solution` | 从步骤数组生成的完整可读参考解答，JSON内换行转义，不增加物理行数 |
| `tables`、`figures` | 表格及必要图示条件，包括第6题有向向量、第15题列联表和临界值表 |
| `source`、`score_source` | 题目、解答及分值的来源与页码 |
| `source_notes`、`scoring_notes` | 提取修正、原文笔误、补足论证及未提供的细化评分规则 |

多选题沿用原卷“全部选对6分，部分选对得部分分，有选错0分”的说明；原PDF未量化部分给分规则，未额外假定。解答题仅提供整题满分，不将步骤序号当作评分点。
